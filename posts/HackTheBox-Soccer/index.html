HackTheBox - Soccer

Soccer is an "easy" difficulty machine, that requires us exploit a known CVE of a file manager. This leads to RCE, which we use to find a second website. The second website is vulnerable to SQLi. The SQLi reveals credentials that were reused for SSH on a user that can run dstat as root, which we abuse to escalate our privileges.
This machine has quite some lateral movement and niche steps involved, which is why I consider it more as a medium than an easy difficulty machine.

Gaining a foothold

The credentials admin:admin@123 worked!
There are two things that catch my eye on entering the website.
First we can see in the URL that the page uses PHP.
Secondly it seems like, that we might be able to upload files to the server. That would allow us to upload a php webshell to gain RCE.

Some testing revealed that the uploaded files are stored in the /tiny/uploads directory.
So I used the “PHP cmd small” shell from https://www.revshells.com/ for my webshell and uploaded it to the site.
I tried if the shell works by running ?0=id within the URL.

Which it did!

The website deletes the uploaded files after a short period of time, so we need to act quick to get a reverse shell going! If this happens just upload the webshell again.

Getting a reverse shell going

First I wanted to see which type of shell is used on the system, which I did by running cat /etc/passwd:

Then I used https://www.revshells.com/ again to set up my reverse shell. I selected “Bash -i” and “/bin/bash” and entered my IP and desired port.
Now comes the “tricky” part. As I wrote earlier, the server deletes the uploaded files rather quick. To reduce the amount of times we need to upload the webshell we can just store the reverse shell to our system, host a Python HTTP server, curl the file from within the webshell and pipe it into the shell. This allows us execute the attack in one go.

Attacking the second website

We found “soc-player.soccer.htb”, which appears to be a domain name we didn’t know about yet.So I added it to my hosts file and entered it.
It appears to have a signup page, which I used to create an account.
After logging in to the page we can check our ticket ID. Entering a wrong ID results in “Ticket Doesn’t Exist” , but entering our ticket ID returns “Ticket Exists”.

This means that there is an actual evaluation of the data we enter, which could mean that it is connected to a database.
So I changed the last digit to a wrong number and combined it with a simple SQL-injection.

It showed “Ticket Exists” again! This means it is using a database in the background.

This type of SQLi is known as boolean-based SQLi. Exploiting it by hand would take ages, though, which is why I decided to use SQLMap.

First I tried to intercept the ticket request with BurpSuite, which didn’t work. I reentered the “Tickets” page and tried to capture my request again.

It appears to be using a web socket on port 9091, which is why we had to intercept the entire request process.

SQLMap

This is a web socket, so we have to specify it as such in our SQLMap URL.

Doas is very similar to sudo. In this case it allows the user Player to run /usr/bin/dstat with root privileges.
Dstat is usually used to monitor Linux system resources in real-time.

So I checked if there are any directories with dstat in their name, where we have write privileges on.

1
2

find / -iname "*dstat*" -writable 2>/dev/null
/usr/local/share/dstat

Read the next steps before you execute the attack. There is a deletion mechanism in place, so you need to be quick!

Dstat allows us to run custom Python scripts, so we need to create a python script that opens a shell, which we store in the writeable directory:

The file name has to start with dstat_ !

1

echo -e 'import os; os.execv("/bin/sh", ["sh"])' > /usr/local/share/dstat/dstat_hacked.py

Then we can use the following command to check if it worked. If it returns “hacked” it worked!

1

dstat --list | grep hacked

And finally we can execute the script like this:

1

doas /usr/bin/dstat --hacked

Conclusion

Soccer can be a very fun, but also very frustating box. It has some very niche mechanics, which I can imagine to be quite frustrating, if you’re not already familiar with them.

All in all, including the niche steps and the amount of lateral movement needed to solve the machine, I think it is more of a medium than an easy machine.

Thank you for reading, have a wonderful day and keep hacking!
